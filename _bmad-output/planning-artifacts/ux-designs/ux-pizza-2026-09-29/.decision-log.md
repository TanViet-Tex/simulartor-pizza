## Concern Scan

- Mobile portrait responsive layout and safe area.
- Touch target size and input ownership.
- HUD hierarchy under three concurrent tickets.
- Nested pause reasons, orientation and foreground return.
- Onboarding without rewarding tutorial actions.
- Save/retry/corrupt-data states at the end-of-day boundary.
- Vietnamese text, non-color-only feedback, mute and audio unlock.
- Pixel-art legibility and motion restraint on baseline mobile hardware.

## Source Reconciliation

- GDD owns gameplay numbers and the exact three-day rules.
- Architecture owns typed commands, selectors, owned pause leases, end-day commit, safe recovery and module boundaries.
- Project context condenses non-negotiable agent rules; it does not replace either source.

## Assumptions Requiring Approval

- Dark-neutral functional UI with food-color accents.
- Vietnamese-capable system sans for functional text until a pixel font is verified.
- Restrained motion and no screen shake for routine interactions.
- Friendly, concise dialogue voice without culture-specific slang.
- Reduced motion may be a demo setting if scope permits; otherwise restrained defaults apply.
